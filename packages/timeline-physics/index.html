How to use (recipe)

First success: PhysicsForceClip — expected: Kick / launch / zero-g / phase through walls / spawn on enter — all from timeline.

  1. Prerequisites: com.bovinelabs.timeline, com.bovinelabs.timeline.entitylinks, com.unity.physics, com.unity.physics.custom on the actor/SubScene.
  2. Open a Playable Director Timeline that bakes with BovineLabs DOTS Timeline.
  3. Add track menu Vex/Physics/Force (type PhysicsForceTrack).
  4. Add clip PhysicsForceClip and bind track to PhysicsBodyAuthoring.
  5. Set the key inspector fields, Bake SubScene, Enter Play, scrub the director.
