Physics-specific mental model (read before coding)

  • Clip is an opinion, not an action — clips vote desires; apply systems write PhysicsVelocity.
  • Five-type stamp (Force example): PhysicsForceData · PhysicsForceAnimated · ActiveForce · force state · mixer — same pattern stamped per family.
  • Two clocks: render (TimelineComponentAnimationGroup) PREPARE/BLEND/WRITE(ECB); fixed (FixedStepSimulationSystemGroup) Producer → solve → Modifier.
  • ECB: BeginSimulation write enables Active* next frame — never write PhysicsVelocity from track systems.
  • Bake: PhysicsTimelineBakingSystem + Ensure<…> stamps body components.
  • IL2CPP: register closed generic jobs in Runtime AssemblyInfo or player builds crash.
  • Tests: start at PhysicsTrackLifecycleTests + apply-half tests (no director required for Active* enable).
  • Full prose: package README (link above) §§ clocks / traps / add-a-family.

Assembly / layer map

Contribution checklist

  1. Add data types in Data assembly (components/buffers only).
  2. Add Clip/Track + baker glue in Authoring.
  3. Add TrackSystem / apply systems in Runtime (respect render vs fixed clocks if physics).
  4. Register Burst/generic jobs in AssemblyInfo if the package uses them (IL2CPP trap).
  5. Add EditMode tests that pin lifecycle + one apply path.
  6. Keep soft-gates as versionDefines + #if — never delete features for vacuum.
