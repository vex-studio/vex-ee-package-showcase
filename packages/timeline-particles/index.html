How to use (recipe)

First success: ParticleSystemClip — expected: Play / stop / burst VFX on companion GOs at exact timeline beats.

  1. Prerequisites: com.bovinelabs.timeline, com.bovinelabs.timeline.entitylinks on the actor/SubScene.
  2. Open a Playable Director Timeline that bakes with BovineLabs DOTS Timeline.
  3. Add track menu Vex/Particles/Play Particle System (type ParticleSystemTrack).
  4. Add clip ParticleSystemClip and bind track to ParticleSystem.
  5. Set the key inspector fields, Bake SubScene, Enter Play, scrub the director.
