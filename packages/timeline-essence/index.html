How to use (recipe)

First success: TimelineEssenceEventClip — expected: Cutscene → gameplay bridge: at this beat, fire OnX / +N counters / while-active buffs.

  1. Prerequisites: com.bovinelabs.timeline, com.bovinelabs.timeline.entitylinks on the actor/SubScene.
  2. Open a Playable Director Timeline that bakes with BovineLabs DOTS Timeline.
  3. Add track menu Vex/Essence/Timeline Event (type TimelineEssenceEventTrack).
  4. Add clip TimelineEssenceEventClip and bind track to TargetsAuthoring.
  5. Set the key inspector fields, Bake SubScene, Enter Play, scrub the director.
