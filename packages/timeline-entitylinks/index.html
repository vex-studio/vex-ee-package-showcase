How to use (recipe)

First success: EntityLinkMutateClip — expected: From this beat on, act on the linked thing instead — follow, stick, swap targets.

  1. Prerequisites: com.bovinelabs.timeline on the actor/SubScene.
  2. Open a Playable Director Timeline that bakes with BovineLabs DOTS Timeline.
  3. Add track menu Vex/Entity Links/Link Mutate (type EntityLinkMutateTrack).
  4. Add clip EntityLinkMutateClip and bind track to TargetsAuthoring.
  5. Set the key inspector fields, Bake SubScene, Enter Play, scrub the director.
