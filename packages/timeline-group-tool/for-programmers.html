Contribution checklist

  1. Add data types in Data assembly (components/buffers only).
  2. Add Clip/Track + baker glue in Authoring.
  3. Add TrackSystem / apply systems in Runtime (respect render vs fixed clocks if physics).
  4. Register Burst/generic jobs in AssemblyInfo if the package uses them (IL2CPP trap).
  5. Add EditMode tests that pin lifecycle + one apply path.
  6. Keep soft-gates as versionDefines + #if — never delete features for vacuum.
