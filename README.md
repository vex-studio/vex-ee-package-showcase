# Vex EE Designer Showcase

Static GitHub Pages site with **HyperFrames** compositions for each vacuumed package.

- Hub: `index.html`
- Per package: `packages/<slug>/` (designer page) + `packages/<slug>/composition/` (HyperFrames project)
- Preview: `tools/hyperframes-showcase.sh preview timeline-physics`
- Lint all: `tools/hyperframes-showcase.sh lint`
